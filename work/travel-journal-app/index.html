04 / UI 与网页 / 移动端 UI

旅历

围绕旅行内容的发现、记录与互动，设计一套以图片为主、路径清楚的移动端旅行社区体验。

项目类型

个人项目

视觉方向

移动端 UI

旅历 · TRAVEL JOURNAL移动端界面设计
项目主视觉接下来设计背景与项目过程

项目档案

从问题出发，记录概念如何转化为具体的视觉表达。

01

设计背景

旅行内容常散落在攻略、图片和社交动态之间。这个练习希望把寻找灵感、浏览内容、关注创作者和记录旅程放进一条更连贯的使用路径。

02

设计回应

界面以旅行图片为视觉主体，使用橙色承担主要操作，配合清楚的字号层级和留白。首页、发现、热门与直播形成内容入口，详情和通知状态补全从浏览到互动的反馈。

03

呈现结果

项目完成了从引导页到内容发现、文章与直播详情，再到点赞、评论、收藏和关注通知的 18 个页面，形成一套较完整的移动端旅行社区概念。

04

参与内容

用户流程界面设计信息层级交互状态
